# Number Guessing Game

A Python command-line game where the user tries to guess a randomly generated number.

## Features

* Random number generation
* Input validation (handles invalid input safely)
* High/low feedback system
* Guess counter
* Clean loop-based game flow

## How to Run

1. Make sure Python is installed
2. Run the file:
   
- python yourfilename.py -

## How It Works

* The program generates a random number between 1 and 1000
* The user enters guesses
* The program tells the user if the guess is too high or too low
* The game continues until the correct number is guessed
